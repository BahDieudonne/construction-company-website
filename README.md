# Amambua Anthony Construction & Engineering

A polished React + Vite multi-page website for a Cameroon-based construction, civil engineering and supply business.

## Quick start

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Content update points

The site is built to be easy to customize from the files below:

- src/config/company.js
- src/config/images.js
- src/data/services.js
- src/data/projects.js
- src/data/products.js
- src/data/testimonials.js
- src/data/team.js
- src/data/blog.js

Update the content and branding there to replace the current production-ready sample text with the company’s final details.
